# 🛍️ Product Management API

This is a simple **Product Management API** built using **Node.js**, **Express**, **MongoDB**, and **Mongoose**. It follows the **MVC pattern** and is intended to serve as a backend for an e-commerce platform or similar applications.

## 📦 Features

- RESTful API for product management
- MongoDB integration via Mongoose
- MVC folder structure
- Environment configuration using `dotenv`
- Auto-reload using `nodemon`
